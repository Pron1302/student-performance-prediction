# Student Performance Prediction System

Internship mini project (AI / ML) – predicts student performance from study habits and background.
**Status: Week 1 and Week 2 complete.**

## Project structure
| Path | Description |
|---|---|
| `generate_dataset.py` | Creates the synthetic student dataset |
| `data/student_performance.csv` | Raw dataset (1,015 rows incl. 15 duplicates) |
| `data/cleaned_student_data.csv` | Cleaned dataset |
| `data/model_ready_data.csv` | Selected features + targets (input for modelling) |
| `Week1_Data_Understanding_and_Analysis.ipynb` | Cleaning, EDA, visualizations, feature selection |
| `Week2_Machine_Learning_and_Finalization.ipynb` | Train/test split, models, tuning, evaluation, prediction system |
| `predict.py` | Command-line prediction system |
| `models/` | Saved final models (`.joblib`) |
| `results/` | Model comparison tables and final metrics |
| `visualizations/` | 13 charts (EDA + model results) |

## Workflow
Data → Cleaning → Analysis → Feature Selection → Training → Testing → Evaluation → Prediction

## Results (test set, 200 students)
**Regression – predict the final score**

| Model | CV R² | Test R² | MAE |
|---|---|---|---|
| **Linear Regression (final)** | 0.740 | **0.829** | **3.79** |
| Ridge (tuned) | 0.740 | 0.829 | 3.79 |
| Gradient Boosting (tuned) | 0.684 | 0.794 | 4.04 |
| Gradient Boosting | 0.673 | 0.763 | 4.41 |
| Random Forest | 0.664 | 0.739 | 4.78 |
| Decision Tree | 0.457 | 0.521 | 6.35 |

**Classification – predict Low / Average / High:** Random Forest, **77 % accuracy**
(strong on Average, weaker on the small High class: recall ≈ 38 %).

A simple linear model won because the scores depend mostly on straight-line relationships.

## Run it
```
pip install -r requirements.txt
python predict.py                       # interactive prediction
jupyter notebook Week2_Machine_Learning_and_Finalization.ipynb
```
Example: 22 study hours, previous score 85, attendance 95 %, assignments 92 %, 7.5 h sleep, tutoring, Master's parents → **87.3 / 100, High**.

## Notes
- The dataset is **synthetic** (generated by `generate_dataset.py`), so results demonstrate the ML workflow, not real student behaviour.
- Selected features: Study_Hours_Per_Week, Previous_Exam_Score, Attendance_Percentage, Assignments_Completed_Pct, Sleep_Hours, Tutoring, Parental_Education.
